# KRISP KDS

Current correction and updater source: [updater/README.md](updater/README.md).

The automated build uses the hash-verified, proven Build 4 native receiver. Historical Android source folders are retained for reference and are not the current build target.

Run **KRISP tested updates** in Actions to test or publish an approved update. Tablet updates are available through **Settings → Check for updates** after installing the updater-enabled build.
