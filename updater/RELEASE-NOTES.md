Adds Settings → Check for updates, with an explicit download/install prompt and Android confirmation. Downloads are limited to the KRISP GitHub release location; package name, size, SHA-256, signing certificate and increasing version code are verified before installation. Tickets and settings remain in the same app.

Also fixes the photographed Precheck → kitchen removal mismatch. A uniquely matching, recent active Precheck from the same P18 source and order number can receive an explicit Removed item print even when the kitchen print adds the POS number or arrives after midnight. Unrelated, completed, old or ambiguous orders are not merged. Item omission still never cancels food.

Both original Build 4 DEX files, icons, resources, TCP receiver, discovery, StationSync and shared parser remain byte-identical. The native green header and launcher label remain B4; the web page header shows Build 7. See the verification and emulator test evidence attached to the release.
